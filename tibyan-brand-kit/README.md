# Tibyan brand kit — start here

Contents: `BRAND_BRIEF.md` (full identity), `logo/`, `icons/`, `animation/`, `motif/`, `tokens/`.

## Prompt to give the AI agent
> You are building the web app "Tibyan" (تبيان), an Arabic RTL app for Islamic content powered by AI. Apply the complete visual identity in this kit.
> 1. Read `BRAND_BRIEF.md` first and follow it exactly (logo rules, motif rules, color meanings, contrast table, checklist).
> 2. Use `tokens/tokens.css` as the single source for colors, gradients and easing; support light and dark themes.
> 3. Use the logo files as provided; do not redraw or recolor them. Use the animated intro (`animation/`) on the splash screen with a `prefers-reduced-motion` fallback.
> 4. Use the decorative **motif** shapes from `motif/` as accents only: one per view or section, never tiled, never joined into a pattern or network graphic.
> 5. Keep the UI minimalist and RTL-first; keep text contrast at WCAG AA using the contrast table.
> 6. Ask before inventing anything not covered by the kit (wordmark, extra illustrations, new colors).
