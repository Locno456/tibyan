# تصدير ومشاركة المحادثة

زر «معلومات المحادثة الحالية» في الترويسة يعرض تصدير JSON لمحادثة واحدة. الملف يحوي رسائلها وإجاباتها ومراجعها، المعرفة المختارة **حالياً**، وجميع المعارف المخصصة للمستخدم؛ راجعه قبل إرساله فقد يحوي معلومات شخصية. لا يسجل النظام تاريخ المعرفة لكل رسالة قديمة.

المستخدم المسجّل فقط يمكنه تشغيل خيار «السماح لمن لديه الرابط برؤية المحادثة». نفّذ `supabase/schema.sql` ثم `supabase/shared-conversations.sql` في مشروع Supabase نفسه. يلزم إعداد `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY`. الرابط يعرض نسخة ثابتة للقراءة فقط من محادثة واحدة والمعرفة المختارة فقط (لا جميع المعارف المخصصة). UUID المحادثة ليس تصريحاً عاماً؛ رابط المشاركة يحوي رمزاً عشوائياً 256-bit، يخزن تجزئته في قاعدة البيانات. RLS يحصر تعديل النسخة في مالكها؛ إجراء RPC مخوّل يرد فقط عند تقديم الرمز المنشور. إيقاف المشاركة يحذف النسخة ويُلغي الرابط، وإعادة النشر تولّد رمزاً جديداً. حذف محادثة من الحساب المسجل يحاول إلغاء نشرها أولاً، ويوقف الحذف إذا فشل الإلغاء. إذا فقدت الجلسة/الجهاز الرابط المنشور، أوقفه وأعد تشغيله لإنشاء رابط جديد.

**قيود مهمة:** النشر ليس آنياً: التغييرات الجديدة لا تظهر إلا بعد إلغاء النشر وإعادة تفعيله. مشاركة محادثة ضيف غير متاحة؛ عند فقد الوصول للحساب لا يمكن إلغاء الرابط من واجهة الضيف. لا تنشر معلومات حساسة. طبّق SQL فعلياً واختبر القراءة المجهولة والإلغاء في مشروعك؛ الاختبارات المحلية لا تثبت نشر قاعدة البيانات. لا تعطِ صلاحية قراءة الجدول لـ`anon`؛ القراءة تتم عبر RPC بالرمز فقط. لم يُفعَّل النشر تلقائياً في البيئة الحية.
