**تحقّق حي:** فُتحت `icadb.com/api/docs` أثناء هذا الفحص وهي تعمل — Swagger «Public read-only API for Central DB»، ومن أطرافها:
```
GET /quran/api/quran/surahs/{surah_no}/ayas/          ← آيات حرفية بمعرّفات
GET /books/api/books/relevant-examples/{iso_code}/     ← Find relevant examples by embeddings
GET /api/encyclopedias/{id}/cards/                     ← بطاقات الموسوعات
GET /api/encyclopedias/versions/{id}/sentences/        ← محاذاة على مستوى الجملة
```
→ **طرف `relevant-examples` يقوم بالاسترجاع الدلالي نيابةً عن `vector_search` المُحاكى في `lib/rag.ts`، مجاناً وبلا مفتاح، من مصدر معتمد رسمياً.** هذا يرفع معيار «جودة الحل التقني 25%» من «محاكاة» إلى «توظيف فعلي بمنهجية واضحة».
