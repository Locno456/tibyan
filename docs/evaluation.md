## حدود هذا التقييم

- تشغيل واحد فقط؛ لا يثبت الاستقرار بين التشغيلات أو عبر البيئات.
- لا اختبار توليد أو صحة مفاتيح أو أسعار/حصص مزودات؛ استخدم `GET /api/health?probe=1` على بيئة مهيأة لاختبار توليد فعلي.
- `GET /api/health?mcp=1` يفحص `initialize` و`tools/list` فقط ولا يختبر `tools/call`.
- هذا التقرير لا يقيس مطابقة نصوص الحديث، كفاية الفتاوى العامة، أو جودة التفسير؛ يلزم لذلك تقييم علمي بشري مستقل.
- مستوى D يُختبر محلياً بالامتناع/الإحالة، لكن نتيجة مجموعة صغيرة لا تثبت تغطية جميع صيغ الحالات الشخصية.
