# تشغيل تِبْيَان بدون Supabase

عند عدم إعداد `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY`، تُحفظ المحادثات والمعرفة المخصصة وتفضيلات الواجهة في **IndexedDB داخل المتصفح**. عند أول تشغيل تُستورد محادثات `localStorage` السابقة، ويُحفظ معها احتياطياً ما أمكن. لا يحتاج التخزين المحلي إلى ملف `.env.local` أو خادم قاعدة بيانات أو تسجيل دخول. أزيل حدّ خمس محادثات في وضع قاعدة البيانات المحلية، ويمكن تصدير المحادثات من الإعدادات. إذا لم يسمح المتصفح باستخدام IndexedDB، يستمر مسار `localStorage` السابق وتظهر رسالة تحذير عند تعذر الحفظ فيه أيضاً.

**حدود صريحة:** IndexedDB مرتبط بالجهاز والمتصفح وقد يُمسح عند حذف بيانات الموقع أو وضع التصفح الخاص؛ لا مزامنة بين الأجهزة ولا حسابات محلية بكلمات مرور. لا يمكن إنشاء رابط عام يقرأه شخص على جهاز آخر من قاعدة متصفح خاصة: يحتاج ذلك إلى خدمة تخزين خادمية ثابتة وإعداد مصادقة/RLS (مثل Supabase). زر تنزيل محادثة منفردة متاح بدلاً منه. لا تحفظ كلمة مرور أو مفتاح API في المتصفح. ميزات التوليد بالذكاء الاصطناعي لا تزال تحتاج مفتاح مزود على الخادم؛ البيانات المرجعية المحلية والمسار الذي لا يحتاج نموذجاً يستمران حسب قدرات التطبيق. هذا المسار لا يشغّل SQLite على Vercel ولا يدّعي دوام تخزين خادم عديم الحالة.

للانتقال لاحقاً: طبّق `supabase/schema.sql` و`supabase/shared-conversations.sql` ثم اضبط متغيرَي `NEXT_PUBLIC_SUPABASE_*` وأعد النشر. بعد تسجيل الدخول يعرض التطبيق قرار دمج/تأجيل بيانات الجهاز بدلاً من رفعها بصمت. احتفظ بتصدير محلي قبل الترحيل أو حذف بيانات الموقع.
