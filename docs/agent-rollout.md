# خطة تفعيل وضع الوكيل تدريجياً

> هذه خطة عمل وليست ادعاءً بأن الميزات أدناه اكتملت أو أن الفوز بالمسابقة مضمون. لا تُغيّر سلوك الإجابة الافتراضي قبل المقارنة والتحقق.

## المرحلة 1 — توافق النماذج (جارٍ)
- [x] تصحيح دور نتيجة الأداة في Gemini: `user` مع `functionResponse` بدلاً من `function`، مع اختبار لهيكل الطلب.
- [x] اختبارات محاكاة للمزود، وفحص TypeScript والبناء.
- [ ] اختبار اتصال حي بنموذج Google عبر تهيئة مفاتيح الخادم ثم `/api/health?probe=1`، واختبار دورة MCP فعلية؛ لا تتوفر مفاتيح في بيئة العمل الحالية.

## المرحلة 2 — مصادر قابلة للتوسع
- [x] سجل خادمي قابل للتوسع لخادمي MCP المعتمدين (`lib/sourceRegistry.ts`) مع رفض تحويل إعدادات الاتصال إلى نطاقات أخرى؛ اختبار إعدادات مصادر إضافية قبل تفعيلها.
- [ ] توسيع السجل للبيانات المحلية والبحث المباشر في نطاقات مسموحة، مع تعريف موحّد للنتيجة والمنشأ والترخيص والمهلة.
- [ ] التحقق من وصول كل موصّل وإثبات صلة المادة بالسؤال؛ لا تُحوّل نتيجة بحث عامة إلى دليل تلقائياً.
- [ ] منع طلبات SSRF وعناوين الشبكات الداخلية وإعادة التوجيه والموارد الكبيرة، والتحقق من URL على الخادم عند إضافة أي موقع.

## المرحلة 3 — إعدادات المستخدم والواجهة
- [x] منتقي متعدد للبيانات المحلية وMCP بجانب زر الإرسال؛ يلتزم الخادم بالاختيار. تعطيل MCP في الواجهة إذا أثبت كتالوج النموذج عدم دعمه للأدوات. البحث في الويب لم يُفعّل بعد.
- [x] «الوضع المتقدم»: عند انعدام الدليل والأدوات يمكن طلب جواب عام من ذاكرة النموذج مع وسم «غير متحقق منها»؛ الافتراضي طلب مصادر. يمتنع عن الاقتباس الشرعي والفتوى الشخصية، ولا يؤكد النسبة دون مصدر. لا يُفعّل الجواب المباشر إذا كان هناك MCP متاح لم يُرجع دليلاً بعد.
- [ ] مواقع مخصصة للباحث المسجل فقط: تحقق خادمي من جلسة المستخدم ونوع الحساب، وفصلها بصرياً عن مصادر المسابقة المعتمدة؛ حدود عدد المواقع والجلب. يعرض الإعداد الآن تنبيهاً بأنها غير مفعّلة، ولا يوجد حقل إدخال مضلل.
- [ ] عرض مراحل تشغيل قابلة للرصد فعلاً بدلاً من كشف سلسلة تفكير النموذج أو إيهام المستخدم ببحث لم يحدث.

## المرحلة 4 — قياس وتحكيم
- [ ] اختبارات أسئلة الحزمة العلمية وأسئلة مفاجئة، ومقارنة المسار القديم والجديد وحالات تعطل المزودين ومخرجات الأدوات الخبيثة.
- [ ] مراجعة بشرية مستقلة للإسناد والنصوص الشرعية والرخص وشروط الاستخدام التجاري لكل مصدر.
- [ ] توثيق قياسات معايير التحكيم النهائي السبعة وحدود الدلالة والتكلفة والخصوصية؛ لا ضمان للنتيجة.
